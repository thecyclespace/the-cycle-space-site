# The Cycle Space

Site web — éducation du cycle, santé féminine et accompagnement en ligne.

## Stack
- Vite + React 18
- Tailwind CSS 3
- Framer Motion

## Démarrer

```bash
npm install
npm run dev
```

Ouvre http://localhost:5173

## Build production

```bash
npm run build
npm run preview
```

## Configuration
- Lien Calendly : `BOOKING_URL` dans `src/App.jsx`
- Couleurs et typographies : `tailwind.config.js`
- Polices Google Fonts (EB Garamond + Inter) : chargées dans `index.html`

## Bilingue
- EN par défaut, bouton EN/FR dans le header.
